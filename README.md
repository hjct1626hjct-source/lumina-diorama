# ✦ LUMINA DIORAMA — Cyber Neon Chronicles —
### 〜星結晶と機械魔王の箱庭〜

> **製作者：駿 (Created by Shun)**

**「立体ミニチュアジオラマ × サイバーネオンファンタジー」** の世界を駆け巡る、最大4人オンライン協力＆ソロ両対応・見下ろし型2Dアクション箱庭探索RPG。  
外部画像・外部音声アセットを一切使用せず、すべて **HTML5 Canvas 2D API・CSS3・Web Audio API** でプロシージャル生成された完全静的サイト構成（GitHub Pages そのまま公開＆iPad PWAホーム画面アプリ化対応）です。

## ✨ ゲームの魅力・搭載システム

### 🎨 1. ドット絵ゼロ！立体ジオラマ × サイバーネオン演出
- **ベクター＆シェーダー風高精細Canvas描画**（Retina / High-DPI対応）：3D押し出し壁・ドロップシャドウ・ネオン発光・剣のスラッシュ軌跡・ダッシュ残像を滑らかな60fpsで描画。
- **エリア別環境パーティクル**：樹海の光胞子、洞窟の霧＆水滴、古代遺跡のデータ粒子、溶岩の火の粉、天空城のオーロラ粒子が常時舞います。
- **極上の手触り（ゲームジュース）**：会心・必殺技・ボス撃破時の**ヒットストップ（0.05秒）＋画面シェイク＋スローモーション演出**、属性弱点・会心・回復の色分けポップアップダメージ数値を完全実装。

### 📱 2. iPad完全最適化＆クロス操作（タッチ / PC両対応）
- **PWAフルスクリーン対応 (`manifest.json`)**：iPad Safariの「ホーム画面に追加」からネイティブアプリ感覚でフルスクリーン起動可能。長押し選択・ピンチズーム・バウンススクロールを完全封鎖。
- **フローティング・バーチャルスティック**：移動エリアのどこに触れても指の位置が中心になる直感マルチタッチ対応。
- **UIカスタム設定**：設定タブからボタンサイズ（標準 / 大きめ）やレイアウト（右利き / 左利き左右反転）、タッチUI表示をリアルタイム切替。

### 🌐 3. サーバーレス最大4人オンライン協力＆チャット（PeerJS）
- **合言葉（ルームID）ロビー**：バックエンドサーバー不要。ホストが4〜6文字の合言葉を発行し、友達が入力するだけで最大4人が即合流（ソロプレイもワンタップで即開始）。
- **カジュアル無双バランス**：マルチプレイ時も敵の強さはソロ基準のまま据え置き！経験値・ゴールド・ドロップ報酬もパーティー全員が気持ちよく獲得できます。
- **熱い協力アクション**：回復・オーバークロック魔法は周囲の味方にも波及。味方が戦闘不能になった際は、近づいてボタン長押しで **「蘇生（レスキュー）」** が可能！
- **チャット＆ワンタップスタンプ**：頭上吹き出し表示付きの開閉式チャット＆8種の定型スタンプ（「よろしく！」「ナイス！」「回復たすかる！」「隠し部屋あった！」「ボス行くぞ！」等）。

### ⚔️ 4. 超本格アクションRPGシステム
- **3大ジョブ**：
  - **ブレイドナイト（剣士）**：高HP＆広範囲ネオンスラッシュ3連撃（3撃目に衝撃波）。必殺技『アストラル・テンペスト』。
  - **アークメイジ（魔導士）**：高MP＆誘導魔弾・初期から氷結＆回復魔法を所持。必殺技『メテオ・プリズムノヴァ』。
  - **シャドウローグ（盗賊）**：超高速移動・高クリティカル・獲得ゴールド+35%。必殺技『ファントム・オーバーロード』。
- **ハクスラ成長・ショップ・鍛冶屋**：モンスターからレア装備・強化鉱石・永久ステータス上昇コアが直接ドロップ。拠点の**鍛冶屋**で装備を `+1〜+10` まで鍛えると武器の発光オーラや斬撃エフェクトが段階的に進化！
- **自律型サポートドローン**：背後を浮遊して敵へ自動レーザー援護射撃＆ドロップアイテム自動吸引回収（ドローン工房でLv.5ツインレーザーまで強化可能）。
- **5種の属性・補助魔法＆コンボ**：ファイアボール（延焼）、アイシクルノヴァ（凍結）、サンダーチェイン（麻痺スタン）、エリアヒール（味方回復＆毒浄化）、オーバークロック（味方ATK/SPD強化）。
- **全5大エリア＋拠点＋隠し部屋＋裏ボス＋エンドレス試練の塔**：
  - 拠点ネオンタウン → 1. 翠光のジオラマ樹海 → 2. 暗闇のクリスタル洞窟（**動的視界制限ライト演出**） → 3. 古代サイバー機工遺跡 → 4. 灼熱のマグマリアクター → 5. 機械魔王の天空城 → **虚空の星核神殿（裏ボス）** → クリア後解放 **エンドレス試練の塔** ＆ **強くてニューゲーム（2周目）**！
  - ヒビ割れた隠し壁（攻撃で破壊）、スイッチ連動ゲート、ダメージ床＆回転刃トラップ、神秘の祭壇、ミニマップ、ファストトラベル（ワープ）、NPC会話、図鑑＆実績、オート＆手動3スロット＋JSONバックアップセーブ、Web Audio APIプロシージャルBGM/SE（6曲＋18種以上）を完全搭載！

## 🎮 操作方法

### 📱 iPad / タブレット操作
| 操作 | 内容 |
| --- | --- |
| 画面左エリア（左利き時は右）ドラッグ | フローティング・バーチャルスティック移動 |
| **⚔ 攻撃**（連打 / 長押し） | 3連コンボ攻撃（隠し壁の破壊も攻撃でOK） |
| **⚡ 回避** | 無敵フレーム付き高速ダッシュ（クールタイムリング表示） |
| **🔥 魔法 / ↻ 切替** | 選択中の魔法を発動 / 習得魔法をクイック切替 |
| **★ 必殺** | リミットゲージ100%でジョブ究極必殺技を発動 |
| **💬 調べる**（タップ / 長押し） | NPC会話・宝箱・祭壇・ワープ / **戦闘不能の味方を長押し蘇生** |

### ⌨️ PC キーボード＆マウス操作
| キー / マウス | 内容 |
| --- | --- |
| `W A S D` / 矢印キー | 移動 |
| `Space` / `J` / **左クリック** | 3連コンボ攻撃（マウス方向へ狙撃） |
| `Shift` / `K` / **右クリック** | 無敵回避ダッシュ |
| `E` / `L` | 選択中の魔法を発動 |
| `Q` または `1`〜`5` | 魔法の切替 |
| `R` / `U` | リミット必殺技（ゲージMAX時） |
| `F` / `Enter` | 調べる・会話・宝箱・長押し蘇生 |
| `M` | 次元ワープ（ファストトラベル） |
| `T` | チャット入力欄を開く |
| `Esc` / `Tab` | メニュー開閉 |

## 🌐 オンライン協力プレイ（合言葉ルーム）の遊び方
1. タイトル画面の **「オンライン協力ロビー（最大4人）」** またはゲーム画面右上の **「🌐 協力」** をタップ。
2. **ホスト（部屋を立てる人）**：合言葉を自動生成（または任意の4〜6文字の英数字を入力）して **「ルームを開設して冒険開始」** を押します。
3. **ゲスト（参加する友達）**：ホストから聞いた合言葉を入力して **「パーティーに合流する」** を押すだけで即合流！
4. 同じエリアに入ると仲間の姿・HPバー・ドローン・チャット吹き出しがリアルタイム同期され、経験値・ゴールド・ドロップもみんなで獲得できます！

## 🚀 GitHub Pages での公開方法
1. 本リポジトリを GitHub の `main` ブランチへプッシュします。
2. GitHub リポジトリの **Settings → Pages → Build and deployment** で **Source: Deploy from a branch / Branch: `main` (`/ (root)`)** を選択して保存します。
3. 数十秒後、`https://<username>.github.io/<repository>/` でそのままiPad・スマホ・PCから遊べます（すべての参照パスが相対パス `./` のためサブディレクトリ環境でも404エラーになりません）。
